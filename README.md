# Персональная онлайн-радиостанция

Статический прототип для GitHub Pages: недельная сетка из 168 часов, редактирование прямо в таблице и хранение состояния в `localStorage` браузера.

`index.html` — интерфейс, `styles.css` — плотная адаптивная сетка, `app.js` — расписание, эфирная позиция, редактор и плееры, `assets/station_id_30s.mp3` — обязательный 30-секундный ID. Исходные `.webloc` сохранены: 15 адресов стали начальными Program; остальные ячейки наследуют Default Source.

Нажмите ячейку, чтобы задать тип (Program, Continue, Jingle / ID), URL, короткое название, стартовую позицию, длительность и локальный ID. В настройках задаются IANA-часовой пояс, Default Source, глобальная длительность и URL ID. Экспорт создаёт JSON; его можно импортировать после очистки браузера или на другом устройстве. Резервная копия имеет вид `{ "settings": { ... }, "slots": { "0": { ... } } }`, ключ равен `день * 24 + час` (`0` — воскресенье 00:00); отсутствующий ключ наследует Default Source.

Позиция вычисляется по времени выбранного часового пояса; последние `idDuration` секунд часа отведены ID. `Intl` учитывает DST: пропущенный час не наступает, повторившийся использует ту же недельную ячейку. YouTube IFrame API и браузер могут задержать запуск, запретить autoplay, не поддержать перемотку либо показать рекламу, поэтому это синхронизация по расчёту, а не гарантия идеальной синхронности. Прямое аудио играет через `HTMLAudioElement`.
